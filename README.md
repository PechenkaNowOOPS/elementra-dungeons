# Elementra Dungeons

Модуль системы физических данжей Minecraft-сервера **Elementra**. Репозиторий подготовлен для дальнейшей работы в **OpenAI Codex** и пока содержит документацию, технические требования и структуру задач; **работающий плагин ещё не реализован и не проверен**.

## Технологический контекст

- Minecraft Java Edition; целевая серверная платформа Purpur/Paper **26.2**.
- Java **25**; никаких обязательных клиентских модов.
- Интерфейсы — игровые взаимодействия, книги, NPC и GUI; команды преимущественно для администратора.
- Данные и все критические игровые решения контролирует сервер.
- Не добавлять масштабные расширения в объём ЗБТ без решения владельца проекта.

## Концепция

В первой версии — подготовленные **физические неинстансовые данжи**, которые существуют в основном мире и имеют отдельные попытки прохождения. Предусмотрены защищённые регионы, комнаты, участники, противники, ловушки, мини-боссы, серверный учёт наград и безопасное восстановление. Никаких обязательных линейных квестов, процедурной генерации для MVP или обязательного выбора народа.

## Как начать работу с Codex

Откройте репозиторий в Codex и передайте задачу из [`docs/codex-first-task.md`](docs/codex-first-task.md). Codex должен сначала проверить доступность нужного API и архитектуру, затем создавать проект Gradle и первый маленький вертикальный срез. Инструкции для агента находятся в [`AGENTS.md`](AGENTS.md).
