# Первое задание для Codex

Проведи техническую подготовку репозитория Elementra Dungeons для первого реализуемого вертикального среза.

1. Прочитай `AGENTS.md`, `docs/dungeons.md`, `docs/decisions.md`, актуальные master-документы из `docs/reference/`. Разделяй закреплённое и предложения.
2. Составь короткую матрицу требований и конфликтов документов. Отметь блокирующие вопросы D-P01, D-P02, D-T02; не придумывай решения за владельца.
3. Проверь реальные координаты и доступность API Purpur/Paper 26.2 и сборки Java 25. Только после проверки создай корректный проект Gradle (включая wrapper), `plugin.yml` и минимальный запускаемый плагин с конфигурацией и безопасным lifecycle.
4. Сделай модели `Dungeon Template` и `Dungeon Run` и минимальную машину состояний, покрытую unit-тестами. Не подключай настоящую экономику/награды без подтверждённого контракта.
5. Не реализовывай сразу полноценные данжи, новых боссов, процедурные комнаты и GUI: ограничь первый PR проверяемым скелетом.
6. Выполни реально доступные сборочные команды и тесты. В отчёте перечисли команды и результаты, а также явно укажи, чего не удалось проверить.
7. Обнови README и документ статуса, не объявляя код release-ready до runtime-проверок.

Предпочтительный результат: один небольшой PR с каркасом проекта, тестами и заметками о несовпадениях требований.
