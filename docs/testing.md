# Матрица проверки — Dungeons

**Состояние:** тест-кейсы; выполнение не заявлено.

| Сценарий | Ожидаемый результат |
|---|---|
| Одновременный старт двух групп | Ровно одна попытка получает физическую локацию |
| Выход в обход входа: жемчуг/элитры/телепорт | Попытка и защита не обходятся |
| Строительство, вода, лава, поршни, TNT внутри | Шаблон не повреждается |
| Пересечение двух регионов | Приоритет правил определён, защита не пропускает обход |
| Двойное открытие лут-контейнера | Награда не дублируется |
| Двойное событие смерти босса | Ровно один результат попытки и один план наград |
| Выход игрока во время боя | Участие и награды обрабатываются согласно выбранной политике |
| Отключение и повторное подключение | Нет второго забега и обхода правила смерти |
| Аварийное завершение процесса при RUNNING | После старта безопасное восстановление без финальной награды |
| Авария во время выплаты | Нет дюпа или потери зафиксированного права на награду |
| Авария во время RESETTING | Возобновление/повтор восстановления идемпотентно |
| Отсутствуют/повреждены блоки шаблона | Данж закрыт `ERROR` до восстановления |
| Снятие администратором | Аудит, корректная очистка сущностей и задач |
| Разгрузка чанков/нет игроков | Нет принудительной загрузки ради пустой попытки |
| Много активных попыток | Контроль MSPT, частиц, объёма задач и сущностей |

Тестовый статус фиксировать отдельно: тест написан, тест выполнен, интеграция проверена, испытание на сервере.
